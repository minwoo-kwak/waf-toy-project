🛡️ WAF 공격 테스트 샘플

주의: 이 테스트는 본인이 소유한 DVWA 서버에서만 실행하세요. 무단으로 다른 서버를 공격하는 것은 불법입니다.

🎯 테스트 대상 URL 설정

프록시를 통해 보호되는 DVWA URL을 입력하세요:

1. 💉 SQL Injection 테스트

SQL Injection 공격은 데이터베이스 쿼리를 조작하여 무단 데이터 접근을 시도합니다.

공격 샘플:

' OR '1'='1
' OR 1=1 --
admin'--
' UNION SELECT null, user(), version() --
1' ORDER BY 3--+

테스트 URL:

클릭하여 SQL Injection 테스트 (새 창)
예상 결과: WAF가 요청을 차단하고 403 Forbidden 또는 406 Not Acceptable 응답을 반환해야 합니다.

2. 🎭 Reflected XSS 테스트

Cross-Site Scripting 공격은 악성 스크립트를 웹페이지에 삽입하여 실행시키려 합니다.

공격 샘플:

<script>alert(1)</script>
<img src=x onerror=alert('XSS')>
<svg onload=alert(1)>
javascript:alert('XSS')
<iframe src="javascript:alert('XSS')"></iframe>

테스트 URL:

클릭하여 XSS 테스트 (새 창)
예상 결과: WAF가 스크립트 태그를 감지하고 요청을 차단해야 합니다.

3. 💻 Command Injection 테스트

명령어 삽입 공격은 시스템 명령어를 실행하려고 시도합니다.

공격 샘플:

; ls -la
&& cat /etc/passwd
| whoami
`id`
$(uname -a)

테스트 URL:

클릭하여 Command Injection 테스트 (새 창)
예상 결과: WAF가 명령어 삽입 패턴을 감지하고 차단해야 합니다.

4. 📁 Local File Inclusion (LFI) 테스트

파일 포함 공격은 시스템 파일에 무단 접근을 시도합니다.

공격 샘플:

../../../etc/passwd
..\..\..\..\windows\system32\drivers\etc\hosts
....//....//....//etc/passwd
/etc/passwd%00
php://filter/read=convert.base64-encode/resource=/etc/passwd

테스트 URL:

클릭하여 LFI 테스트 (새 창)
예상 결과: WAF가 경로 조작 시도를 감지하고 차단해야 합니다.

5. 📤 악성 파일 업로드 테스트

이 테스트는 실제 파일 업로드 폼에서 수행해야 합니다.

테스트 방법:

  1. DVWA의 Upload 페이지로 이동
  2. 아래 확장자의 파일을 업로드 시도:
test.php
malware.exe
script.jsp
backdoor.asp
shell.phtml
DVWA Upload 페이지 열기
예상 결과: WAF가 위험한 파일 확장자를 감지하고 업로드를 차단해야 합니다.

🔍 종합 테스트 버튼

모든 공격을 순차적으로 테스트합니다 (새 탭에서 열림):

이 버튼은 여러 공격을 연속으로 실행합니다. WAF 로그를 확인하여 차단 여부를 검증하세요.

테스트 후 다음 명령어로 WAF 차단 로그를 확인할 수 있습니다:

kubectl logs -l app=nginx-ingress -n ingress-nginx | grep -i "denied\|blocked\|403"
