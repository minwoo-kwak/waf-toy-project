📊 테스트 결과 확인 방법
==========================================

예상 결과:
✅ 정상 차단: 403 Forbidden / 406 Not Acceptable / 400 Bad Request
❌ 차단 실패: 200 OK (WAF 설정 점검 필요)

WAF 로그 확인:
kubectl logs -l app=nginx-ingress -n ingress-nginx | grep -i "denied\|blocked\|403"

또는 WAF 대시보드에서 실시간 로그 모니터링
